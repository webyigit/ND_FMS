# 부가기능 설계 (v1, 2026-10-07)
근거: 요구사항정의 '부가기능' 3종. 자료에 없는 결정은 **[제안]** 또는 [확인 필요]로 표시.

## 0. 공통
| 구분 | 주소(별도 URL) | 접속 권한 | 화면 |
|---|---|---|---|
| 부서장 모바일 | `/m` | role = 부서장(dept_head), 관리자가 회원설정에서 부여 | 모바일 전용 레이아웃 |
| 지출신청하기 | `/request` | role = 부서장 또는 목회자(pastor) | 모바일 우선 |
| 기부금영수증 신청 | `/donation-request` | 로그인 없음(공개) | 모바일 우선 |

- 관리자 화면(`/dashboard` 등)과 레이아웃·메뉴를 분리한다. 외부 노출 주소는 관리자 메뉴로 이동할 수 없다.
- 신청 건은 모두 **신청 → 재정부 검토(승인/반려) → 반영** 흐름. 승인된 지출신청은 지출입력의 금주 목록으로 들어간다. **[제안]**
- 관리자 메뉴에 **신청관리**(지출신청·예산신청·기부금영수증 신청)와 **공지사항** 추가.

## 1. 부서장 전용 모바일 페이지 `/m`
| 화면 | 기능 |
|---|---|
| 로그인 `/m/login` | 기존 계정(소셜·SMS) 로그인. 부서장 권한 없으면 차단 안내 |
| 홈 `/m` | 내 부서 예산·지출·잔액·집행률 요약, 최근 공지 |
| 예산·지출 조회 `/m/budget` | 항목별 예산, 지출 내역(일자·내용·금액·비고) |
| 예산 신청 `/m/budget-request` | 연도·항목·금액·사유. 내년도 예산 편성 화면에서 참고 **[제안]** |
| 지출 입력 `/m/expense/new` | 영수증 사진 촬영·업로드 → AI 인식으로 일자·업체·금액·품목 자동 입력 → 수정 → 신청 |
| 내 신청 내역 `/m/expense` | 조회, 승인 전 건만 수정·삭제 **[제안: 승인 후에는 잠금]** |
| 공지사항 `/m/notice` | 관리자가 올린 공지 열람 |

- 한 사용자가 여러 부서를 맡을 수 있게 `user_department`로 연결. **[제안]**
- 사진은 Storage 비공개 버킷에 저장, 서명 URL로만 조회.
- 사진 인식은 AI 비전 API 사용 [확인 필요: API 비용 허용].

## 2. 지출신청하기 `/request`
- 부서장: 자기 부서만 선택 가능.
- 목회자: 부서 선택 없이 지출만 신청(부서·항목은 재정부가 검토 시 지정).
- 입력: 내용, 금액, 사용일, 영수증 사진, 송금받을 계좌(본인 계좌 기본값).
- `/m/expense/new`와 같은 신청 테이블(`expense_request`)을 쓴다. 차이는 부서 지정 여부뿐.

## 3. 기부금영수증 신청 `/donation-request` (공개)
- 입력: 이름, 주민번호, 주소, 영수증 발행자명(영수증에 기재될 기부자명) [확인 필요: '발행자명'의 정확한 의미], 가족명단.
- 이름으로 지난 발행내역을 찾아 개인정보를 불러오고 가족명단(헌금 시 함께 입력된 이름)을 채워 준다. 수정 가능.

### 보안 [제안] — 공개 페이지라 필수
요구사항대로 **이름만으로 주민번호·주소를 불러오면 누구나 타인 정보를 조회할 수 있습니다.** 아래를 적용합니다.
1. **본인 확인 후 불러오기**: 이름 + 휴대폰 문자 인증(OTP) 성공 시에만 지난 정보 로딩. 문자 인증이 어려우면 이름 + 생년월일 + 휴대폰 뒤 4자리 일치로 대체.
2. **마스킹**: 불러온 주민번호는 뒤 6자리, 주소는 상세주소를 가려 보여줌. 바꿀 때만 전체 재입력.
3. **봇 차단**: Cloudflare Turnstile(무료) 캡차 + 숨김 필드(honeypot).
4. **요청 제한**: IP·전화번호 기준 분당/일당 횟수 제한, 실패 반복 시 일시 차단.
5. **저장**: 주민번호는 서버에서 즉시 암호화(pgcrypto), 로그에 평문 금지. IP는 해시로만 기록.
6. **동의**: 개인정보 수집·이용 동의 체크 필수, 보관기간 명시 [확인 필요: 보관기간].
7. **결과 노출 최소화**: 신청 완료 화면에 접수번호만 표시. 영수증 파일은 재정부 승인 후 발급(문자/이메일 링크는 [확인 필요]).
8. HTTPS 전용, 관리자 화면과 분리된 API, 서버에서만 DB 접근(서비스 키는 클라이언트에 노출 금지).

## 4. 관리자 쪽 추가 화면
| 메뉴 | 화면 |
|---|---|
| 신청관리 > 지출신청 | 목록·영수증 사진·인식결과 확인 → 부서·항목 지정 → 승인(지출입력으로 인입)/반려 |
| 신청관리 > 예산신청 | 부서별 신청 → 내년도 예산 편성에 반영/반려 |
| 신청관리 > 기부금영수증 신청 | 신청 → 개인별 헌금 합산 확인 → 영수증 발행 화면으로 이동/반려 |
| 설정 > 공지사항 | 공지 작성·수정·게시 대상(부서장/전체) |
| 설정 > 회원설정 | 권한에 부서장·목회자 추가, 부서장-부서 연결 |
