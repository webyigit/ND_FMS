## 헌금 구분
- 일반회계: 십일조, 주일헌금(총액만), 감사헌금(범사감사/기타감사/일천번제), 신년감사, 기관헌금(유치부/아동부/중고등부/청년부), 절기(부활절/맥추절/추수/성탄절)
- 특별회계: 이웃사랑, 꽃꽂이, 건축(E/V)
- 별도기금: 해외선교, 네팔(긴급)구호 → 일반/특별 합계 제외

## 검증 시트 로직
A 농협잔액 + B 입금예정 = C 실잔액 / D 해외선교 미입금잔액 / E = C − D / F 장부잔액 누계 / G = E − F 유용가능 / H 기준잉여금(전년이월) / G − H → 일치·부족

## 금주 보고서 레이아웃
결재란 → 수입/지출(일반·특별: 지난주잔액 A, 수입 B, 지출 C, 잔액) + 차입현황 → 특별헌금 → 지출상세(순번,내용,금액,부서,항목,비고) → 해외선교 → 해외선교/네팔
