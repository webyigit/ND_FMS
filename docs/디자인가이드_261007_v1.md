## 1. 원칙
- 밝은 회청색 바탕(`#f7f9fb`) 위에 흰 카드. 테두리 없이 아주 옅은 그림자로 구분한다.
- 강조색은 초록 하나(`#22c55e`). 버튼, 활성 메뉴, 링크에만 쓴다.
- 상태색(수입·지출·경고)은 강조색과 별개로 의미에만 쓴다.
- 글자는 작고 촘촘하다(본문 13px). 숫자가 많은 재정 화면에 맞다.
- 다크 모드 지원(`data-theme="dark"`).

## 5. 레이아웃
```
┌──────────┬─────────────────────────────────────┐
│ 로고      │ 상단바: 메뉴접기 · 인사말 · 검색 · 알림 · 사용자 │
│ (270px)  ├─────────────────────────────────────┤
│ 사이드바   │ 페이지 제목 + 경로(breadcrumb)          │
│ 메뉴      │ KPI 카드 행                           │
│          │ 차트 카드 / 목록 카드 (12열 그리드)        │
│          │ 표 카드                               │
│          │ 푸터                                  │
└──────────┴─────────────────────────────────────┘
```
- 사이드바: 고정, 폭 270px, 접으면 70px(아이콘만). 모바일(<1024px)에서는 숨기고 햄버거로 연다.
- 상단바: 원본 높이 120px(로고 영역과 맞춤). NDFMS2는 72px로 줄여 쓴다(화면 효율).
- 본문: 좌우 여백 24px, 최대폭 없음(유동). 12열 그리드.
- 반응형: `≥1280` 4열 KPI, `≥768` 2열, 그 아래 1열.

## 6. 컴포넌트 패턴

### 사이드바 메뉴
- 그룹 라벨(대문자 11px) 아래 항목. 항목 = 아이콘(18px, muted) + 글자(13px/500), 안쪽 여백 10px 16px.
- 호버·활성: 글자와 아이콘이 primary. 활성 항목은 primary-subtle 배경을 깐다(NDFMS2 추가 규칙).
- 하위 메뉴: 앞에 작은 점(•), 들여쓰기.

### KPI 카드
- 좌: 라벨(muted 12~13px) → 큰 숫자(24px/600) → 변화량(배지 + 설명).
- 우: 48px 원형 아이콘 배경(subtle) + 원색 아이콘.
- 변화량: 증가 `▲ 8.5%` success, 감소 `▼ 3.2%` danger.

### 카드
- 헤더: 제목(16px/600) 왼쪽, 오른쪽에 기간 선택 드롭다운이나 "더보기". 헤더 아래 구분선 없음.
- 본문: 차트, 표, 목록.

### 표
- 머리행: surface-2 배경, 500 굵기, muted 글자.
- 행 구분: border 색 1px 아래선. 호버 시 surface-2.
- 금액 열: 오른쪽 정렬, tabular-nums, 원 단위 쉼표.
- 상태 열: subtle 배지.

### 배지
- 기본은 subtle: 연한 배경 + 원색 글자, 모서리 0.25rem, 11~12px, 500.
- 강조가 필요하면 원색 배경 + 흰 글자.

### 버튼
- primary(채움), outline, subtle(soft) 세 가지. 높이 약 34px.
- 아이콘 버튼은 정사각 34px.

### 입력
- 테두리 border 색, 모서리 0.4rem, 포커스 시 primary 테두리 + primary 15% 링.

### 차트
- 원본: ApexCharts. 계열 순서: primary → success → info → warning → purple → pink.
- 그리드 옅게(border 색), 축 글자 muted 11px. 영역 차트는 그라디언트 채움(위 30% → 아래 0%).
- NDFMS2: 수입은 success, 지출은 danger로 고정(2장 재정 의미 매핑 우선).

### 아이콘
- **Font Awesome 6 Free로 통일** (2026-10-07 결정). 무료판만 쓴다(아이콘 CC BY 4.0, 코드 MIT).
- 스타일: 기본 `fa-solid`, 알림·테마처럼 가벼운 곳은 `fa-regular`. 크기 메뉴 16px, KPI 원형 20px, 목록 15px. 폭 고정(`fa-fw` 또는 width 1.25em).
- Next.js: `@fortawesome/react-fontawesome` + `@fortawesome/free-solid-svg-icons` + `@fortawesome/free-regular-svg-icons`, `config.autoAddCss = false` 후 `@fortawesome/fontawesome-svg-core/styles.css` import.

## 8. 구현 메모 (Next.js + Tailwind)
- `tokens_261007_v1.css`를 `app/globals.css`에서 import 한다. Tailwind v4면 같은 파일의 `@theme` 블록이 `bg-primary`, `text-muted`, `shadow-card` 같은 유틸리티를 만든다.
- 다크 모드: `<html data-theme="dark">`. Tailwind는 `@custom-variant dark (&:where([data-theme=dark], [data-theme=dark] *));`.
- 금액 표시는 공용 컴포넌트 하나(`<Amount value type="in|out" />`)로 색·부호·쉼표를 통일한다.
