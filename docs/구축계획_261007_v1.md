# NDFMS2 재정관리시스템 구축계획 (v1, 2026-10-07)

근거: Drive "_ND_FMS/요구사항정의" 문서. 자료에 없는 내용은 [확인 필요].

## 1. 범위 (요구사항 기준 메뉴)
0. 로그인/회원가입/ID·PW 찾기 (관리자 승인제, 소셜로그인, SMS 본인확인)
1. 대시보드 (금주 리포트·특이사항 알람, 주간 수지, 전년 동월/분기 비교, 부서별·헌금구분별, 인사이트)
2. 수입관리 (과거내역, 수입입력, 은행거래내역 업로드, 금주 수입 리포트, 개인별 헌금현황)
3. 지출관리 (과거내역, 지출입력[고정지출·은행엑셀·PDF 영수증 인식·송금파일], 부서별, 검증시트, 금주 리포트, 고정지출, 계좌관리)
4. 해외선교 (주간 수입/지출, 월 누적)
5. 기부금영수증 (발행, 양식관리, 발행현황, 교회정보·직인/간인, 지난 발행내역, 발행번호 규칙)
6. 예산결산 (당해 결산, 내년 예산·이월금, 리포트)
7. 설정 (회원 권한, 재직명단, 교인명단·가족·노출순서, 헌금구분, 사용이력)

## 2. 기술 스택 (기본안)
- 웹: Next.js(App Router) + TypeScript + Tailwind, Rizz 템플릿 스타일 추출해 재현
- DB/인증/파일: Supabase(PostgreSQL + Auth + Storage, RLS로 권한)
- 소셜로그인: 카카오·네이버(OIDC/OAuth). 토스·다음 [확인 필요: 토스는 사업자 제휴 필요 가능성]
- SMS 본인확인 무료안: Firebase Phone Auth 무료 한도 사용 또는 카카오 로그인 연동으로 대체 [확인 필요: 무료 한도·요금]
- 엑셀: SheetJS (농협 등 은행 엑셀 파싱, 송금파일 생성)
- PDF 영수증 인식: LLM 비전(Claude API) 또는 Tesseract OCR [확인 필요: API 비용 허용 여부]
- 출력: A4 인쇄 CSS + PDF(서버 렌더), Excel 저장, Google Drive 저장(Drive API)
- 헌금/지출 자동분류: 과거 입력내역 기반 규칙(이름·적요 매칭) + 수정 가능
- 배포: Vercel 등 [확인 필요]

## 3. 단계
1. 설계: DB 스키마, 권한, 화면 목록 / Drive 샘플(재정부(2026) 월별 파일) 구조 분석
2. 기반: 인증·승인·권한, 교인명단·가족, 헌금구분, 설정
3. 수입관리 + 금주 수입 리포트
4. 지출관리 + 고정지출·은행엑셀·송금파일·PDF 인식·검증시트
5. 기부금영수증 (정부 양식 그대로 출력)
6. 대시보드·해외선교·예결산·사용이력
7. 과거 데이터 이관(Drive 엑셀 → DB), 검증, 배포
